# Come installare la demo ODISPEL V3 (testo per itch.io)

## Android

1. Scarica l'APK della versione che vuoi installare.
2. Se è già installata una versione ODISPEL V3, installa l'aggiornamento sopra la precedente.
3. Se Android segnala che l'app proviene da una fonte sconosciuta, autorizza temporaneamente l'installazione da quella fonte.
4. Se compare Play Protect, valuta l'avviso prima di proseguire.

**Importante — firma:** dalla versione 0.33.0 gli aggiornamenti sono installabili sopra la versione precedente soltanto se l'APK è firmato con la stessa chiave privata. Non disinstallare la versione esistente per risolvere un errore di firma prima di aver verificato di avere un APK firmato con la chiave originale: disinstallando potresti perdere i salvataggi locali. Se la chiave originale non è disponibile, una nuova firma richiede la disinstallazione e comporta la perdita dei dati locali dell'app.

Pacchetto Android: `com.gialloo.odispel.v3`.

## Windows

1. Scarica lo ZIP ed estrailo interamente in una cartella.
2. Mantieni insieme l'eseguibile e il file `.pck` (oltre agli eventuali file inclusi nell'esportazione).
3. Avvia `OFFICIAL_DEMO_ODISPEL.exe`.

Windows può mostrare un avviso per applicazioni indipendenti non firmate con un certificato commerciale. Procedi soltanto se hai scaricato il pacchetto dalla pagina ufficiale ODISPEL su itch.io.

## Versione e integrità

Controlla sempre che il numero di versione indicato nella pagina itch.io corrisponda al pacchetto scaricato. Quando disponibile, confronta il file con il relativo hash SHA-256 pubblicato insieme alla release.
